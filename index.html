./thesis

Analysis & Implementation of Cloud Development Environment and Platform-as-a-Service for the Web Application Development Practicum

“Analisis dan Implementasi Cloud Development Environment dan Platform-as-a-Service pada Praktikum Web Application Development Prodi Sistem Informasi Universitas Telkom”

Installing and configuring local dev environments was slowing down Telkom University's Web Application Development practicum — OS mismatches, weak hardware, and setup errors, plus inefficient screenshot-based grading. Using a case-study method (foundation → prefield → field → reporting), I implemented and benchmarked 4 Cloud Development Environments and 4 PaaS providers for the class.

Result: GitHub Codespaces + Koyeb — free, no credit card required, powerful specs, easy to use, and low latency — outperformed the existing setup on almost every parameter, giving students an inclusive, efficient, and scalable practicum workflow.

advisors: Umar Yunan Kurnia Septo Hediyanto, Muhammad Fathinuddin
publisher: Universitas Telkom, S1 Sistem Informasi · Bandung
